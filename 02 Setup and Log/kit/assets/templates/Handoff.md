## How To Refresh With New Data
1. Put the new raw file in `Raw Data` (keep the old one; never overwrite).
2. Re-run `05 Cleaning and Prep/clean_data.py`, then the integrity check.
3. Re-run `pivot_builder.py` (07, 08) and `web_dashboard.py` (09) with the same specs, then the tests.
4. Compare the new totals with `Findings.md` and update the findings.
